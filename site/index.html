This is the whole idea

Click any small tile. It flies to the middle, the big one drops into the slot it just left, and every other tile holds still — no re-spacing, nothing to re-find. Add a few, or try the other modes. This is the same code the app runs.

Tip: press 1–9 to send a tile to the middle, or Esc to leave Solo.

  • Stage — the defaultOne at full size in the middle, the rest small down the sides. Click a small one and the two swap places.
  • GrowEverything stays in one grid, and the tile you're working in takes more of it. The Size slider sets how much.
  • EqualEvery tile the same size, always. Nothing moves when you click.
  • SoloThe tile you're in fills the window and the rest collapse away. Esc brings them back.

The reason it exists

Every project gets its own agent view

Claude Code's agent view lists each agent as its own row — what it's working on, and whether it's waiting on you. But that list is machine-wide: every project you have open, stacked in one column. Claufy hands each tile the same view narrowed to that tile's folder, so a tile only ever shows its own project's agents.

Claude's default — one shared list

Twelve agents, four projects, one column to read.

Claufy — one view per folder

Hover or tap a folder — that's everything it can see.

  • One project per tileFour repos, four shells, four agent views — none of them showing each other's work.
  • See who needs youThe agent view marks a session waiting for input. With a tile each, you spot it without switching windows.
  • Long jobs stay visibleA build, a training run, a tail -f keeps a live tile down the side while you work in the middle.
  • Pin what the shell producesPut localhost, a dashboard or the docs in a tile beside the terminal building it.
Real shells

Not a fake terminal

Every tile is a real login shell, so your aliases, prompt and PATH are exactly what you already have.

Not only terminals

Any web app tiles too

Point a tile at localhost, a dashboard, docs, or any web app and it spaces itself with the rest. Native desktop apps can't be embedded by any cross-platform toolkit, so those still open in your OS.

Sharp

Text never gets blurred

No tile is ever scaled. Growing one animates the grid tracks; swapping one is a plain translate and a width change, so its text is clipped and revealed rather than resampled. A scaled terminal turns its glyphs to mush — this one stays crisp on every frame.

Everywhere

macOS, Windows, Linux

One app window with tiles inside — not a window manager, so nothing takes over your OS.

Why "Claufy"? The name comes from Claude. The first version existed to run a stack of Claude terminals on a Mac — all the same size, one per project — because that was the thing there was no good way to do. It tiles anything now, and terminals are still what it's for, but that's where the name came from.
